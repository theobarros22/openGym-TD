# openGym-TD — previa brasileira

Abra `Abrir-openGym-TD.cmd` e mantenha a janela aberta durante o uso.
Endereco: http://localhost:4173

A previa utiliza o modo mobile local. Novos perfis iniciam em portugues do Brasil.
Os dados desta previa ficam no navegador deste computador. Use a exportacao de backup do aplicativo para guarda-los.

Esta entrega e uma previa web, ainda nao e um APK. O SDK Android precisa ser configurado para gerar e testar o instalador.
A base original e openGym, sob AGPL-3.0-or-later; os avisos e a licenca foram preservados.
